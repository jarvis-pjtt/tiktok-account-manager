# TikTok Account Manager

โปรแกรมเดสก์ท็อป (Windows) สำหรับ **จัดการหลายบัญชี TikTok — ล็อกอิน และเปิดบัญชี** เท่านั้น
แต่ละบัญชีใช้โปรไฟล์ Chrome แยกของตัวเอง (คุกกี้/session ไม่ปนกัน)

## ฟีเจอร์
- ➕ สร้างบัญชี (โปรไฟล์ Chrome แยกต่อ 1 บัญชี TikTok)
- 🌐 **เปิดบัญชี** — เปิดหน้าต่าง Chrome ที่ผูกกับบัญชีนั้น (ถ้ามี session อยู่แล้วจะเข้า TikTok ได้ทันที)
- 🔐 **ล็อกอินอัตโนมัติ** — กรอกอีเมล/รหัสผ่านให้เอง และอ่านรหัส OTP จากกล่องเมล Outlook/Hotmail ที่ผูกไว้
- 🔑 เก็บอีเมล/รหัสผ่าน TikTok + ข้อมูลกล่องเมล OTP (เข้ารหัสด้วย Windows DPAPI)
- 👥 เช็คสถานะบัญชี / ยอดผู้ติดตาม, 📋 คัดลอกข้อมูลบัญชี, 🗑 ลบบัญชี

> โปรแกรมนี้ **ไม่มี** ส่วนดาวน์โหลด/ตัดคลิป, แคปชั่น, AI และการโพสต์ ถูกตัดออกทั้งหมดแล้ว

## ติดตั้ง
```
pip install -r requirements.txt
```
UI เขียนด้วย tkinter/ttk ล้วน (มากับ Python อยู่แล้ว) ไม่ต้องลง GUI framework เพิ่ม
ต้องมี Google Chrome ติดตั้งในเครื่อง (หรือเปลี่ยน `chrome_channel` ในแท็บตั้งค่าเป็น `msedge` /
เว้นว่างเพื่อใช้ Chromium ของ Playwright แล้วรัน `playwright install chromium`)

## ใช้งาน
```
python main.py
```
หรือดับเบิลคลิก `run.bat`

### ขั้นตอน
1. แท็บ **บัญชี** → พิมพ์ชื่อ → "➕ สร้างบัญชี"
2. เลือกบัญชีในตาราง → **"🌐 เปิดบัญชี (Chrome)"** (หรือดับเบิลคลิกที่แถว) → ล็อกอิน TikTok ในหน้าต่างที่เปิด →
   ปิดหน้าต่างเมื่อเสร็จ (โปรแกรมจะอ่านไอดี/ผู้ติดตามให้อัตโนมัติ)
3. อยากให้ล็อกอินเอง: กด "🔑 อีเมล/รหัสผ่าน" ใส่บัญชี TikTok + บรรทัดเมล OTP
   (`email|pass|refresh_token|client_id`) แล้วกด **"🔐 ล็อกอินอัตโนมัติ"**
   ถ้าเจอ CAPTCHA ต้องกดเองในหน้าต่าง Chrome

## บิ้วเป็น .exe
ดับเบิลคลิก `build.bat` จะได้ 2 อย่างใน `dist\`
- `TikTokAccountManager\` — โฟลเดอร์โปรแกรม ก็อปไปใช้ได้เลย (รัน `TikTokAccountManager.exe`)
- `TikTokAccountManager-v<เวอร์ชัน>.zip` — ไฟล์สำหรับอัปขึ้น GitHub Release (ตัวอัปเดตอัตโนมัติใช้ไฟล์นี้)

ข้อมูลทั้งหมด (บัญชี + การตั้งค่า) อยู่ในโฟลเดอร์ `data` ข้างไฟล์ .exe — zip ไม่มี `data` ติดไปด้วย
เครื่องปลายทางต้องมี Google Chrome ติดตั้งอยู่

## อัปเดตอัตโนมัติ (GitHub Releases)

### ตั้งค่าครั้งเดียว
1. สร้างรีโป **สาธารณะ** บน GitHub (โค้ดจะเปิดเผย ถ้าไม่อยากเปิดโค้ด สร้างรีโปเปล่าไว้แจกไฟล์อย่างเดียวก็ได้)
2. เปิดโปรแกรม → **ตั้งค่า** → ช่อง `GitHub repo สำหรับอัปเดต` ใส่ `owner/repo` เช่น `xzin/tiktok-account-manager`
3. ติ๊ก "ตรวจหาเวอร์ชันใหม่อัตโนมัติตอนเปิดโปรแกรม" (เปิดไว้อยู่แล้ว)

### ปล่อยเวอร์ชันใหม่
1. แก้เลขเวอร์ชันใน `app/__init__.py` → `__version__ = "1.1.0"`
2. รัน `build.bat` → ได้ `dist\TikTokAccountManager-v1.1.0.zip`
3. GitHub → Releases → **Draft a new release** → tag `v1.1.0` → แนบไฟล์ .zip → เขียนรายละเอียดใน body (จะเด้งให้ผู้ใช้เห็น) → Publish

### ฝั่งผู้ใช้
เปิดโปรแกรม → 3 วินาทีต่อมาเช็คให้เอง → ถ้ามีใหม่จะเด้งถาม → กดตกลง = โหลด zip → ปิดโปรแกรม → ก็อปทับ → เปิดใหม่เอง
กดเช็คเองได้ที่เมนู **⋯ → ตรวจหาเวอร์ชันใหม่**

> ตัวอัปเดตใช้ `robocopy /E` คือ **ก็อปทับอย่างเดียว ไม่ลบอะไรทิ้ง** และข้าม `data` เสมอ — บัญชีกับการตั้งค่าไม่หาย
> ถ้าอัปเดตมีปัญหา ดู log ที่ `%TEMP%\tam_update.log`
> อัปเดตอัตโนมัติทำงานเฉพาะเวอร์ชัน .exe (ตอนรันด้วย `python main.py` จะแค่บอกว่ามีเวอร์ชันใหม่)

## โครงสร้างข้อมูล
```
data/
  settings.json       การตั้งค่า + selectors ของหน้า TikTok (แก้ได้ถ้า TikTok เปลี่ยนหน้าเว็บ)
  profiles/<ชื่อ>/    โปรไฟล์ Chrome ของบัญชีนั้น + profile.json (อีเมล/รหัสผ่านที่เข้ารหัส + สถิติ)
```

## หมายเหตุ
- รหัสผ่าน TikTok และ refresh_token ของกล่องเมล เข้ารหัสด้วย Windows DPAPI (ถอดได้เฉพาะบน user/เครื่องเดิม)
- ถ้าปิด Chrome แล้วสถานะยังค้างว่า "เปิดอยู่" (เช่น Chrome ค้างเป็น process เบื้องหลัง) กด "🧹 ล้างสถานะค้าง"
  แล้วเปิดใหม่ได้เลย ไม่ต้องรีโปรแกรม — ถ้ายังขึ้นว่าเปิดอยู่ ให้ปิด chrome.exe ใน Task Manager ก่อน
- ย้ายบัญชีเดิมจากโปรแกรมตัวเก่า: ก็อปโฟลเดอร์ `data\profiles\<ชื่อ>` มาไว้ที่ `data\profiles` ของโปรแกรมนี้
